# PR-17 초안

- 공통 활동 소개 화면에서 시작하기를 누르면 플레이어가 시작 안내 문장을 음성으로 읽는다. 안내는 마지막 화면과 같은 글 중심 형식으로 보여주며, 안내가 끝나면 추가 클릭 없이 보기 5 단계로 진입한다. 브라우저 음성을 사용할 수 없는 경우에만 “음성 없이 첫 단계로” 대체 버튼을 보여준다.
- 보기 5 → 촉각 4 → 청각 3 → 후각 2 → 미각 1 → 마무리. 자동 타이머로 다음 단계에 넘어가지 않는다.
- 첨부 그림의 감각 모양을 참고해 눈·손·귀·코·입을 배경 없는 SVG 선 그림으로 표시한다. 선은 화면 테마 토큰을 따르며 사진 배경·하트는 사용하지 않는다.
- 안내와 감각별 예시는 BE content_spec에서 읽는다. 배경 음악·강제 타이머·감각 답 입력은 없다.
- 음성은 브라우저 TTS이며 첨부 MP3의 목소리나 전사가 아니다. 연구 대본 재현이라는 주장도 하지 않는다.
- 다음/건너뛰기는 현재 음성을 취소한다. 한 단계라도 건너뛰면 completed false와 단계 이름만 보고한다. 실제 알아차린 감각 내용은 저장하지 않는다.
- 실제 세션에서는 공통 시작 버튼이 음성을 활성화한다. 직접 /dev 플레이어에 진입해 브라우저가 자동 음성을 막으면 음성 없이 진행하는 대체 버튼을 사용할 수 있다.
- preview.py --backend <BE 경로>는 origin/feat/#114의 명세로 로컬 PR-17 fixture를 생성한다(TEMP 백업). fixture 자체는 커밋하지 않는다.
- 모바일 360×780/393×852, 테마 다섯 세트, 기기별 TTS, 중단·빠른 전환은 수동 확인 필요.
